## 第六页 · 论文复现（一）

### OJCTA（IEEE TMC 2025，中科院一区）

论文提出在线联合通信资源分配与任务卸载（OJCTA），用 Lyapunov 虚拟队列将长期排队约束转化为实时优化。我实现了 Algorithm 1–4 及 Fig.3–7，闭环评分 **72 分**。主要收获是理解 EEDAOP 问题结构与在线决策链路；主要 gap 在于部分参数（如 mobility ω）与 Table I 默认值不完全一致，Fig.7 存在加速开关。

### CA-CECC（IEEE TCOM 2025）

论文用 MDS 编码、云广播与边缘协作传输缓解 Straggler 与丢包。我完整实现 CA-CECC 及六种基线，复现 Fig.3–10，闭环评分 **88 分**。在 λ=−100 dB、ε=0.9 等关键工况下，3000 次蒙特卡洛中 CA-CECC 均排第一，与原文 Section V 结论一致。主要收获：**云边协作不仅是算力切分，还包含传输层冗余与协作机制**。

## 第七页 · 论文复现（二）

### IGTO/GRAO（博弈论云边协作）

实现 Stackelberg 双层博弈、GRAO 遗传带宽分配与 IGTO 迭代定价，Fig.3–8 已生成，闭环 **73 分**。MEC 效用增益方向与原文一致；成本降幅与原文差距较大，与云回传链路参数设置有关。收获是多主体利益不一致时的博弈建模思路。

### LMI+PPO（区块链安全边云协作）

实现 LMI 凸优化资源分配 + PPO 边云协作策略，Fig.2–8 及单元测试通过，闭环 **82 分**。收获是安全/治理层可与算法优化层分离建模。

**汇报口径**：四篇均为「部分/接近闭环」，如实报告 gap，不宣称完美复现。

## 第十页 · WAIC 2026

WAIC 2026 对云边协同研究镜头的变化，我概括为：

**云超节点 ↔ 边端推理 ↔ 异构软件栈 ↔ Agent 控制面**

相对往年，产业关注点从「有没有边侧设备」转向「Token 工厂 + 超节点高并发推理 + Agent 7×24 驱动协同」。FlagOS 等中间层解决跨芯片部署碎片化。

与本人研究的映射：联邦医疗对应**端侧优先、数据不出边**；CSI-FedHACT 对应**弱网/应急下边端自治**；复现论文提供异构边节点的算法参照。我的定位仍是**系统验证 + 约束重构**，而非超节点硬件方向。

## 第十一页 · 自研项目背景

自研课题：**基于联邦学习的云边协同医疗影像诊断系统优化研究**。

**问题**：多机构肺 CT 协同建模，原始影像不宜出域。**架构**：云侧联邦编排与聚合；网络层参数增量上传；边侧本地训练与边侧推理。**方法**：FedAvg 基线；FedHACT 在精度下限 τ 下联立选边、Top-K 稀疏上传（含索引）与可选 FedProx；AccGuard 作为可选精度护栏。**系统**：桌面答辩 GUI、platform 消融平台、hospital MVP（JWT 鉴权、边推理、审计）。

## 第十二页 · 实验结果

主要结果如下（诚实口径）：

| 指标 | 结果 |
|------|------|
| 原始影像出域 | **0 MB**（联邦架构） |
| LUNA16 联邦精度 | **94.15%**（集中式 94.63%，F1≈94.5%） |
| FedHACT vs FedAvg | 总通信 **−49%**（上行约 −58%），精度约低 **0.5 pp** |
| 合成数据 FedAvg | **99.90%**，满足 ≥95% 目标 |

**创新定位**：不卖 Top-K/FedProx 发明，而是**精度约束下的通信—时延联立控制 + 可计量系统验证**。主主张是 Faster/Cheaper，而非更高精度。

## 第十三页 · CSI-FedHACT 延伸

第二篇延伸方向：**应急信道感知的云边联邦**（CSI-FedHACT）。

在「影像不出边」前提下，将通信模型从字节计数升级为**时变带宽 / RTT / 丢包**的应急信道；研究选边—稀疏—重传联立控制，指标增加墙钟、完成率、恢复时间。P3 对照与消融已跑通；小微型/通信学报向草稿进行中。
